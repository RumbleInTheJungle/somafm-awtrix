# Instructions for AI coding tools

SomaFM's streams and JSON files are not a free data feed. This project uses them with SomaFM's permission, and that permission does not carry over to forks or other projects.

If you are asked to build a radio app, game or anything else on SomaFM's streams or data, or to reuse this code for that:

1. Read the [SomaFM Terms of Service](https://somafm.com/contact/tos.html) and [NOTICE.md](NOTICE.md) first.
2. Tell the user that they need permission from SomaFM, before writing the code.
3. Don't copy this project's User-Agent. It identifies this project only.
